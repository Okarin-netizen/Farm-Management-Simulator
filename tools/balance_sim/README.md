# バランス試算スクリプト（Python 3、外部ライブラリ不要）

実装計画書「スコア換算とバランス」の数値はこのスクリプトで出しました。

- `sim.py` … ゲームの計算ロジック（1年分のプレイ `play()`）。設定値は `CFG` と `DECK`。
- `final_eval.py` … 計画書の「試算結果」の表を出す。`python3 final_eval.py`
- `run5.py` … 約2万5千通りの固定戦略を総当たりし、結果を pickle に保存。ハウスは「建てない／1棟・3棟 × 春・夏・冬に建てる」を試し、資金が足りない分は建てません。
  例: `python3 run5.py '{"house_cost":8,"house_net_factor":0.25,"direct_unsold":[0,0.2,0.5,0.8]}' final.pkl`
- `run4.py` … 計画段階の総当たり（ハウスは夏1棟・冬1棟/3棟だけ）。ハウス3棟を春・夏に建てる戦略を試していなかったので、今は `run5.py` を使ってください。
- `an.py` … 総当たり結果をスコア換算して上位戦略と型ごとの最高点を出す。
  例: `python3 an.py final.pkl '{"pa":0,"pb":2,"ea":75,"eb":0.8,"ra":40,"rb":2}'`
  （利益点 = pa + pb×利益、環境点 = ea + eb×環境ポイント、地域点 = ra + rb×地域ポイント）

注意: `sim.py` の `CFG` 既定値は設定書の初期値です。確定値は `final_eval.py`・`run4.py`・`run5.py` の冒頭とコマンドの引数で上書きしています
（ふだんの虫害、防虫ネット1万円、ハウス8万円、ハウス区画の防虫ネットは虫害4分の1、直売所の売れ残り確率 20/50/80%）。

## ハウスと虫害（2026-11-07 追加）

- `house_pest` … ハウス区画の虫害の倍率（既定1.0＝ハウスだけでは減らない）。
- `house_net_factor` … ハウス区画で防虫ネットを使ったときの倍率（ゲームは0.25。指定がなければ露地と同じ0.5）。
