# 農家経営シミュレーション

中学校 技術分野「C 生物育成の技術」で使うブラウザ型ゲーム教材です。1年間（春・夏・秋・冬）農家を経営し、「利益」「環境」「地域」の3つのバランスがよい農業を目指します。

- `index.html` 1ファイルだけで動きます（外部ライブラリ・通信・保存なし）。GitHub Pages で公開し、Chromebook でURLを開くだけで遊べます。
- 数値（費用・確率・倍率・スコア換算）と画面の文言は、`index.html` 冒頭の `CONFIG` と `COMMENTS` にまとまっています。

## 効果音

タイトル画面とサイドパネルの「効果音：あり／なし」で切り替えます。最初は「なし」で、設定は保存しません（ページを開くたびに「なし」から）。音はブラウザで合成していて、音声ファイルは使っていません。端末で「視差効果を減らす」設定がオンのときは、動きの演出も止まります。

## 先生向けの機能

| URL | 内容 |
|---|---|
| `index.html` | 通常のゲーム |
| タイトル画面の「コード」 | 同じコードを入れた生徒は、同じ天気・できごとの1年になります（空欄なら毎回ちがう） |
| 最終画面の「同じ1年でもう一度」 | 2回目を1回目と同じ天気・できごとの1年で遊び、最終画面に1回目との差を表示します（ページを開いている間だけ覚えます。保存はしません） |
| `index.html?seed=123` | シードを固定して同じ展開を再現 |
| `index.html?test=1` | 計算の検算テスト（計画書の検算例など19件） |
| `index.html?sim=2000` | 代表的な10戦略を各2000回自動プレイし、計画書の試算結果と比べる |

## コードの構成（index.html）

`index.html` の `<script>` は2つあり、上から次の順に並んでいます。

| 章 | 内容 |
|---|---|
| 0. PICTO | ピクトグラム（SVG）。`pic('spinach')` のように使う |
| 1. CONFIG | 数値と文言。単位は万円、倍率は小数 |
| 2. RNG | シード付き乱数。同じコードなら同じ1年になる |
| 3. ENGINE | 計算（`computeSeason` など）。画面にはさわらない |
| 4. COMMENTS | 最終画面のふりかえりコメントのルール |
| 5. UI | 画面ごとの HTML（`screens.plan` など）とボタンの処理（`actions`） |
| 6. DEBUG | `?test=1` と `?sim=2000` |
| 7. 演出レイヤー（2つ目の script） | 効果音・カウントアップ・ワイプなど。`render()` を包み直して足すだけで、計算にはさわらない |

数値を変えたら `?test=1` と `?sim=2000` を開いて確かめてください。演出レイヤーは画面の文字を読まず、本体が付けた `data-*` 属性（`data-money`・`data-yield` など）から数字を読みます。

## バランス試算スクリプト

`tools/balance_sim/` は計画段階で使った Python 版の試算です（Python 3、外部ライブラリ不要）。使い方は同フォルダの README を参照してください。
