# 農家経営シミュレーション

中学校 技術分野「C 生物育成の技術」で使うブラウザ型ゲーム教材です。1年間（春・夏・秋・冬）農家を経営し、「利益」「環境」「地域」の3つのバランスがよい農業を目指します。

- `index.html` 1ファイルだけで動きます（外部ライブラリ・通信・保存なし）。GitHub Pages で公開し、Chromebook でURLを開くだけで遊べます。
- 数値（費用・確率・倍率・スコア換算）と画面の文言は、`index.html` 冒頭の `CONFIG` と `COMMENTS` にまとまっています。

## 先生向けの機能

| URL | 内容 |
|---|---|
| `index.html` | 通常のゲーム |
| タイトル画面の「コード」 | 同じコードを入れた生徒は、同じ天気・できごとの1年になります（空欄なら毎回ちがう） |
| `index.html?seed=123` | シードを固定して同じ展開を再現 |
| `index.html?test=1` | 計算の検算テスト（計画書の検算例など12件） |
| `index.html?sim=2000` | 代表的な8戦略を各2000回自動プレイし、計画書の試算結果と比べる |

## バランス試算スクリプト

`tools/balance_sim/` は計画段階で使った Python 版の試算です（Python 3、外部ライブラリ不要）。使い方は同フォルダの README を参照してください。
